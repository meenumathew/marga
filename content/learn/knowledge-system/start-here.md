# Knowledge System Start Here

Use this library as a pull system, not a reading backlog. Start with the work in front of you, choose the smallest note that helps, then create one visible output.

## Choose The Mode First

| Need            | Mode        | Output                                    |
| --------------- | ----------- | ----------------------------------------- |
| Learn by doing  | Tutorial    | Running example or project log            |
| Complete a task | How-to      | Finished decision, checklist, or artifact |
| Look up facts   | Reference   | Correct detail applied                    |
| Understand why  | Explanation | Short explanation in your own words       |

## Operating Loop

1. Name the work in front of you.
2. Pick the smallest note that helps that work.
3. Read only the fast path and relevant section.
4. Apply it to code, a decision, or an explanation.
5. Log the output as evidence, then stop reading.

The scorecard and section mastery are earned from evidence you produce, not from notes marked read. See [Why Evidence Beats Reading](../practice/why-evidence-beats-reading.md).

## Quality Bar

Good notes have one mode, one trigger, a fast path, and an output. If a note does not change what you build, decide, test, explain, or track, close it.
